# NOVA overview and navigation

Mode: Read on Overview, Operate on Market/Activity/Settings. Extend the existing
navy/light/system-font console. User approved fictional digital equity; keep
synthetic/Testnet context in ordinary visible copy, with all actual values outside
the illustrative bitmap. This document describes the console extension only.

## Direction contract

THESIS: explain what NOVA represents and what each wallet action accomplishes.
OWN-WORLD: existing cool light ground, navy ink, blue actions and role colors;
no new typeface, motion or framework. FIRST VIEWPORT: asset explanation and Open
market link on the left; full NOVA demo certificate on the right, stacked on
mobile. STORY: understand the asset, follow the lifecycle, choose a working tab.
FORM: extend the existing interface with native navigation and numbered process
steps; no replacement visual world or page comp. FINISH: browser evidence,
independent finish review, this design record and embedded image provenance.

## Implemented structure

NovaAssetSummary shows the asset name, whole-share unit, HBAR payment currency,
Testnet ID and illustration. AssetLifecycle renders six ordered steps with an
explicit cancellation/expiry return branch in text. OverviewPage adds the three
account responsibilities and tab destinations. Layout uses existing prefixed
Tailwind, a two-column first section at lg and three process/role columns at md.

MarketPanel remains the single mounted owner of order intent, draft, matching
queries and selected settlement. AccountBalance, OrderBook, OrdersTable and
MatchesList are presentational extractions using existing table/control styling.
Activity displays these same order/match views while hiding the market ticket;
selecting a match or cancellation returns to Market. Existing Market history
access remains available. ActivityPage groups historical T02–T05 evidence and
read-only verification; SettingsPage retains account/network/SDK setup.

Overview is the default; explicit Market hashes still open trading directly.
Native #trade/#history links resolve to Activity. #main skip navigation retains
the selected page. Header role colors and sticky positioning remain unchanged.
All components remain mounted across tabs to retain current operations; inactive
market polling stops outside Market/Activity. New-order consent and transaction
checks are still owned by the existing controllers.
